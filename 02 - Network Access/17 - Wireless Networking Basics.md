# Wireless Networking Basics

- **SSID**: wireless network name; one AP can advertise multiple SSIDs.
- **AP**: radio connection to the wired LAN.
- **WLC**: manages and coordinates APs in controller-based designs.
- **2.4 GHz**: greater reach but limited non-overlapping channels; **5 GHz**: more spectrum and often better capacity.
- **WPA2/WPA3**: wireless security generations; use strong authentication, disable insecure legacy modes.
- **CAPWAP**: control/data tunneling between lightweight APs and WLCs in Cisco architectures.

## Troubleshoot
Check SSID, correct VLAN mapping, channel/interference, authentication method, DHCP assignment and uplink reachability.
