# Network Architectures

## What they describe
A network architecture describes **how equipment is organised**, where traffic travels, and how the design can expand.

| Design | Key idea | Typical use |
|---|---|---|
| Two-tier | Access switches connect to a collapsed distribution/core layer | Small and medium campus |
| Three-tier | Access, distribution, and core each have distinct roles | Large campus |
| Spine–leaf | Every leaf connects to each spine; predictable east–west paths | Data centres |
| WAN | Connects geographically separated sites | Branch to headquarters |
| SOHO | A compact network with router, Wi-Fi, endpoints | Home/small office |
| On-premises vs cloud | Services hosted locally or by a cloud provider | Hybrid environments |

**Access** connects endpoints; **distribution** aggregates access and applies policy; **core** transports traffic quickly across the campus.

### Quick checks
- Why do data centres prefer short, predictable leaf-to-spine paths?
- Which design layer connects a user's laptop?
