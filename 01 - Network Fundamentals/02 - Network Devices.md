# Network Devices

## Router
Connects IP networks and forwards packets using a routing table. Operates primarily at OSI Layer 3. See [Routing Table and Administrative Distance](../03%20-%20IP%20Connectivity/02%20-%20Routing%20Table%20and%20Administrative%20Distance.md).

## Layer 2 switch
Connects devices in Ethernet VLANs and forwards frames using learned MAC addresses. See [Switching and MAC Learning](../02%20-%20Network%20Access/01%20-%20Switching%20and%20MAC%20Learning.md).

## Layer 3 switch
Combines switching with routing, often through **SVIs** or routed interfaces. See [Router-on-a-Stick and SVI Routing](../02%20-%20Network%20Access/08%20-%20Router-on-a-Stick%20and%20SVI%20Routing.md).

## Other common devices
- **Firewall**: separates zones using security policies, often NAT and VPN.
- **Wireless AP**: provides radio access to wired LAN.
- **WLC/controller**: manages APs and WLAN policy.
- **Servers/endpoints**: provide/consume application services.
